# Foodie (v1.0)

Личный дневник еды: что понравилось, что нет и где это было куплено или съедено.

- Категории: «Магазины» (группы Еда / Десерты / Фрукты) и «Кафе и рестораны»
- Оценка 1–5 звёзд, заметка и дата у каждого продукта
- Поиск по блюду и заведению, «Лучшее и худшее» с картинкой для шеринга
- Все записи с группировкой по местам, оценкам и датам
- Резервная копия: копирование и восстановление текстом

Один файл `index.html`, без библиотек. Данные хранятся только в браузере устройства (localStorage), на сервер ничего не отправляется.

**Версия 1.0 заморожена.** Развитие идёт в новом проекте Goodies.
